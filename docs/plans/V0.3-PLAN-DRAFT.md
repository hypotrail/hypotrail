# v0.3 plan — draft for owner review (2026-10-20)

Inputs: [OWNER-DEMO-2-REMARKS.md](../acceptance/OWNER-DEMO-2-REMARKS.md) (R12–R38), a fresh journey review (chat only, chat + panel) and a fresh panel UI review (mockups kept outside the repo until validated). Status: proposal; nothing here is implemented.

## 1. Diagnosis

- **The journey is not smooth because of the engine, not only the copy.** The agent hits engine refusals the junior then sees: text that passes `check` is refused by `propose` (`literal_number_in_text`); single-feature scores cannot be cited; a stale revision is returned after the opening confirmation; `check` matches a number to the wrong result by value (R33); diagnostics go stale after the first adoption of the same rule (R34).
- **Confirmation is a lottery.** Lexical endorsement lists plus reason rules produce visible refusals. R27 (owner): paraphrase and reasons only in training mode; in guided mode an endorsement suffices for every decision. R16: interactive choices, recorded with channel `choice`.
- **The agent reads too much.** About 65 tool calls and 60–70k words per study, prompt above 8k words. Payloads are agent-shaped, English, and long; the agent re-explains and sometimes contradicts the engine (R32).
- **The panel duplicates the chat and looks wrong.** Root cause of the visual drift: mockups used a private palette, the implementation uses theme variables; spec §13/§15.1 themselves impose sideways scroll and underlines. Bugs: "train 0" (CV `rowsSeen`, `lib/models/eda.js:286`), raw tokens, clipped labels. R23 (owner): decisions only in chat.
- **The discovery case is incoherent (R31).** Online Shoppers labels a session by its own outcome; the target is known at the moment of prediction. Proposed replacement: Hotel booking demand, Resort Hotel (R38).

## 2. Targets (measured in agentic acceptance)

Per study on the discovery case: ≤ 12 junior turns to conclusion; 0 engine refusals shown to the junior in guided mode; ≤ 4 tool calls per pause; agent prompt ≤ 4k words; every number in chat, HTML and notebook traced by `check`; panel gate green at 3 widths × 3 themes, FR and EN.

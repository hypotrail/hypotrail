horsepower porte le code « ? » sur 6 des 318 lignes de développement, soit 1,9 %.

Exemple

La voiture de la ligne L331 n'a pas de puissance : sa cellule vaut « ? ». Le modèle reçoit un indicateur horsepower=? et une valeur imputée, jamais le nombre zéro.

Pourquoi ça tient

L'indicateur laisse le modèle apprendre si l'absence elle-même dit quelque chose ; l'imputation est apprise pli par pli, sur les lignes où chaque modèle est ajusté.

Règle d'une erreur type outil

À cette étape C'est la règle que le mode automatique a appliquée au choix du modèle, la décision qui vous attend. Elle répond à « parmi des configurations proches, laquelle retenir ? ». La comprendre vous permet d'adopter ce choix ou de le changer en connaissance de cause, dans le chat.

Règle d'une erreur type : parmi des configurations comparées sur les mêmes plis, retenir la plus simple dont l'erreur moyenne est à moins d'une erreur type de la meilleure.

La meilleure moyenne est celle de l'EBM, 3,40, avec une erreur type de 0,61 : la barre est à 3,40 + 0,61 = 4,01. Le modèle linéaire, à 3,70, passe sous la barre et il est le plus simple : il est retenu.

Moyenne des plis et la barre d'une erreur type
Pourquoi ça tient

Avec 5 plis, l'erreur bouge d'un pli à l'autre (écart-type d'environ 1,5 mpg entre les plis). Un écart de 0,30 entre deux moyennes peut venir de la façon dont les voitures sont tombées dans les plis. À précision comparable, le modèle le plus simple se lit et se défend mieux. Hastie, Tibshirani et Friedman (2009), §7.10.

Où ça casse
  • Les plis sont les mêmes pour toutes les configurations. L'écart apparié EBM moins linéaire, −0,30 [−0,49 ; −0,12], reste sous zéro : sur les mêmes voitures, l'EBM fait probablement un peu mieux. La règle, elle, regarde la dispersion de chaque moyenne séparément.
  • Choisir la meilleure de 3 configurations sur les mêmes plis la flatte : optimisme approximatif de 0,04.
  • La question qui reste est la vôtre : un gain d'environ 0,3 mpg vaut-il un modèle moins simple, pour l'usage prévu ?

La règle protège contre un gain dû au hasard des plis ; l'écart apparié dit si le gain tient sur les mêmes lignes. Vous décidez si 0,3 mpg compte.

Ce qui compte comme votre réponse mode guidé

  • Une réponse adopte la proposition ouverte : « oui, je l'adopte » suffit, ou un oui bref à la question « Adoptez-vous cette décision ? ».
  • Ce n'est pas une réponse si elle pose une question ou garde une condition comme « oui, mais » ou « sauf si ».
  • Une raison est facultative, aussi pour le choix du modèle et la conclusion ; sans raison, l'enregistrement indique « aucune raison donnée ».
  • Le mode ne change que dans le chat, avec vos mots ; ce panneau ne peut pas le changer.

Hétéroscédasticité culture

À cette étape Les diagnostics viennent après l'ajustement : ils regardent où et comment le modèle se trompe, sur les prédictions hors pli. Ce constat ne change pas l'erreur moyenne, mais il pèse sur ce que vous pourrez affirmer dans la conclusion, que vous direz dans le chat.

Hétéroscédasticité : des erreurs dont la taille change avec la prédiction ou d'un groupe à l'autre.

La dispersion des résidus est 2,58 fois plus grande dans le tiers des prédictions les plus hautes : le modèle se trompe davantage sur les voitures qu'il prédit les plus sobres.

Où ça casse

L'erreur moyenne reste un résumé honnête, mais une même largeur d'intervalle pour chaque voiture serait fausse. Cette étude ne donne pas d'intervalle de prédiction.

5 maillons · cliquez pour révéler après avoir dit
  1. Pourquoi 3,69 mpg est-il optimiste ?
    Ces prédictions hors pli ont servi à comparer et à choisir parmi 3 configurations : le chiffre retenu est flatté par le choix.
  2. Que dit −3,47 [−3,97 ; −2,96] ?
    Sur les mêmes voitures, le linéaire se trompe de 3,47 mpg de moins que la moyenne ; l'intervalle reste sous zéro, le gain ne vient pas du hasard du rééchantillonnage.
  3. Pourquoi la règle d'une erreur type garde-t-elle le linéaire alors que l'EBM fait 3,40 ?
    3,70 est à moins d'une erreur type (0,61) de 3,40 : à précision comparable, on garde le plus simple. L'écart apparié, lui, favorise l'EBM de 0,3 mpg.
  4. Que signifie un résidu moyen de +5,27 sur 1981–82 ?
    Le modèle prédit en moyenne 5,27 mpg de moins que la réalité pour les voitures récentes : il suit mal la dérive dans le temps.
  5. Pourquoi les 80 lignes scellées comptent-elles ?
    Elles n'ont servi à rien encore : ouvertes une fois, après le choix, elles donnent le seul chiffre indépendant de l'étude.

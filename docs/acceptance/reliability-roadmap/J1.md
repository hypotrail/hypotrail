# J1 implementation and acceptance

Date: 22 October 2026. Base before the combined implementation:
`58f048c363215a52131c6991878105e6509a6a59`. No historical final test was read,
reset or reopened.

## Implemented scope

- One pure explicit planner, schema `hypotrail.evaluation_plan/1`, with canonical digest.
- Stratified, quantile, group-disjoint, forward-chaining and ordered-retrospective plans.
- Strict prediction/outcome-clock eligibility, complete time ties, gaps and warm-up rows.
- Transitive entity plus duplicate components and training-only overlap purges.
- Exact outer memberships consumed by fitting; compatible inner plans for nested tuning.
- Review final partitions record their analysis protocol and exact training exclusions.
- Legacy split behavior and previously opened studies are not migrated or reinterpreted.

## Validation record

The J1--J3 focused acceptance set passed (75 tests), followed by the impacted engine set
(333 tests). The official complete engine gate later passed with 1,871 tests and 94 opt-in
agent scenarios skipped. The Hotel, Bank full and Online Shoppers builders passed their
check/verify modes; the Auto MPG and Bank Marketing migrations passed `--check`.
After the final documentation update, the combined J0--J3 acceptance and frozen-contract
set passed 122 tests.

After the complete gate, a presentation-only defect found by the companion tests was fixed:
variant questions are now frozen outside the numerical input identity. Its post-fix engine,
fixture-drift and browser regression set passed (31 tests). No evaluation-plan logic changed
after the complete engine run.

## Limits

An explicit plan cannot make inaccessible source data physically secret. Unsupported
dependence or an infeasible clock/group layout is refused, not silently approximated.
This milestone does not implement J4 history inheritance or J5 semantic claim checking.

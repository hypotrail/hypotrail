# J2 implementation and acceptance

Date: 22 October 2026. J2 was tested after J1 was green and before J3 was admitted.
No historical final test was inspected.

## Implemented scope

- Hard scenario-specific availability restrictions on proposal, confirmation and run paths.
- Derived `requirements`, `completion` and `claim_eligibility` surfaces with one frozen shape.
- Current model/rule-specific diagnostics before opening and final diagnostics after opening.
- Hard interpretability admission and explicit planned/diagnostic-informed variant provenance.
- Inconclusive conclusions may state missing evidence; empirical claims may not omit it.

## Validation record

J2 was admitted only after the J1 targeted set passed. Its targeted tests then passed before
J3 work started, and the combined J1--J3 focused set passed 75 tests. The impacted engine set
passed 333 tests and the official complete engine gate passed 1,871 tests with 94 opt-in agent
scenarios skipped. The later presentation-only follow-up did not change validity logic; its
31-test engine/fixture/browser regression set passed. The final combined J0--J3 acceptance
and frozen-contract set passed 122 tests.

## Limits

Consent remains agent-reported and the repository does not enforce cross-study exposure.
Calibration diagnostics are evidence, not automatic permission for a calibration claim.

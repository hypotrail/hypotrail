# v0.1 acceptance checklist

Status: run at the v0.1 closure, 18 October 2026, on branch `claude/hypotrail-product-review-yrstzb`. This is the checklist of [plan §7](../plans/V0.1-IMPLEMENTATION-PLAN.md#7-acceptance-checklist), row by row, with the evidence that exists.

Evidence types:

- **U** unit and **S** simulated tests (real `hypotrail` CLI processes, real signals, headless Marimo, offline Playwright). "Pass" means passed in the closure gate run below. Counts are test cases, parametrised cases included.
- **A**: Claude Code agentic acceptance, from the reports in [`runs/`](runs/): the [first run](runs/claude-code-2026-10-18.md) (S1–S9), the [rerun](runs/claude-code-2026-10-18-rerun.md) after D1–D12, and the [final check](runs/claude-code-2026-10-18-final.md) after R1–R7, plus the E1 arm B runs ([report](../research/runs/E1-arm-B-2026-10-18.md)). **This is not Copilot acceptance**, it ran on Opus with simulated juniors, and each condition ran once per round: a pass is weak evidence.
- **Not proven**: nothing establishes the behaviour; the reason is given.

## Outside the checklist and not proven

- **GitHub Copilot**: the instruction files are generated but never run (directive A1).
- **A human junior's understanding**: every agentic run used simulated juniors; E1 measures an agent's study validity, not learning.
- **Failure rates**: the plan asked for N repetitions per scenario; every condition ran once per round, so no rate exists.
- **Policy and conclusion confirmations by a junior who delegates**: the scripted persona never gives a valid reply at pause 3; only one answering-persona run confirmed them.
- **Auto MPG generality**: refused as a regression with a declared group column; validated only as a refusal.

# v0.2 acceptance checklist

Status: run at the v0.2 closure, 19 October 2026, on branch `claude/hypotrail-product-review-yrstzb`. One row per owner remark of [demo 1](OWNER-DEMO-1-REMARKS.md) (R1–R11) and per decision of the [review synthesis](../plans/V0.2-REVIEW-SYNTHESIS.md) (§1 findings, §4 sequence, §5 owner answers), with where it is implemented, how it is verified, and a status. The decisions taken along the way are in [V0.2-DECISIONS.md](../plans/V0.2-DECISIONS.md); the ones most worth review in [V0.2-OWNER-REVIEW.md](../plans/V0.2-OWNER-REVIEW.md).

Evidence types:

- **U** unit and **S** simulated tests (real `hypotrail` CLI processes, headless Marimo, offline Playwright, the panel's real controller on the real CLI). Paths are relative to `framework/tests/study/` unless they start with `clients/` or `framework/`. "Pass" means passed in the closure gate run below.
- **A**: Claude Code agentic acceptance on `claude-opus-5-5` with scripted or simulated juniors, N = 3 per scenario and case, from [the v0.2a run](runs/claude-code-2026-10-19-v0.2a.md) (Bank, S0–S11) and [the v0.2b run](runs/claude-code-2026-10-19-v0.2b.md) (Online Shoppers, Bank full, Auto MPG, Bank; S0, S1, S6, S8, S10–S13). A run is named `<release> <scenario> <case>`; the figure is the latest round.
- Status: **done** (built and verified at the level stated), **partial** (built, with a named gap), **not proven** (nothing establishes it, reason given).

## Not proven

- **No human junior** has used v0.2 (owner decision: no observation gate). Every agentic run answers a scripted or simulated junior; comprehension, workload and trust are unmeasured.
- **No GitHub Copilot.** The Copilot instruction files are generated from the same templates and never run. All agentic evidence is Claude Code on `claude-opus-5-5`.
- **No real VS Code session.** The panel, its Marimo buttons, its themes, the Marimo extension picking the interpreter of `.vscode/settings.json`, workspace trust and the chat insertion are tested with a fake `vscode` module and Playwright only ([MANUAL-TEST.md](../../clients/vscode-companion/MANUAL-TEST.md) is "not run").
- **Online Shoppers** (and Bank full) come from public GitHub mirrors checked against UCI's published counts, **not compared byte for byte with the UCI archive**; Online Shoppers' variable descriptions are recalled (`scenario_assumption`), not read from the source.
- **Heuristic lexical rules.** Endorsement, reason, relation, partial-refusal and concept checks, the contradiction warning, `feature_basis`, `check`'s number binding and evidence scopes, and the agent graders are English and French word lists. Known false acceptances exist ("oui, la pizza du client est bonne pour la campagne"); each v0.2b `check` fix widened what a figure may match.
- **N = 3 agent runs** per scenario and case, short scenarios from a scripted state; no full study from step 0 to the conclusion; E1 not rerun. Round 2 re-ran only what a fix touched, once; the S13 calibration-binding fix and the S1 recap miss (Online Shoppers en) are not confirmed by a run.
- The Marimo spike was not rerun at this closure (Marimo unchanged).

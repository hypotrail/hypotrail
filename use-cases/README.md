# Use cases

Each case owns its data, provenance, business context, and preparation scripts. The reusable engine lives in `../framework/`.

| Case | Task | Role |
|---|---|---|
| [Hotel booking demand](hotel-booking/README.md) | Binary cancellation scoring of new bookings (Resort Hotel), temporal final test by arrival date | Discovery case from v0.3; data derived from a public mirror and committed (CC BY 4.0), `case.yaml` generated by `build_case.py` |
| [Bank Marketing](bank-marketing/README.md) | Binary subscription classification | v0.1/v0.2a acceptance case (`bank.csv`, 10 % sample) |
| [Bank Marketing, full file](bank-marketing-full/README.md) | Binary subscription classification, temporal final test | Generality case from v0.2b (`bank-full.csv`, in time order); `case.yaml` generated by `build_case.py` |
| [Auto MPG](auto-mpg/README.md) | Regression in mpg | Second case for adaptation checks |
| [Breast Cancer Wisconsin](breast-cancer-wdbc/README.md) | Binary malignant/benign classification | Generality check (M3); data copied from scikit-learn by `prepare.py`, not committed |
| [Diabetes progression](diabetes/README.md) | Regression without a time column | Generality check (M3); data copied from scikit-learn by `prepare.py`, not committed |
| [Online Shoppers Purchasing Intention](online-shoppers/README.md) | Binary purchase scoring of finished sessions | Advanced case since v0.3 (the v0.2b discovery case): its target is known at its prediction moment (README, R31); data committed (CC BY 4.0), `case.yaml` generated by `build_case.py` |

Current `registry.json`, `project.json`, and `results.json` files are tutorial contracts (Bank Marketing and Auto MPG only; the two scikit-learn cases, the two v0.2b cases and Hotel booking demand have a generated `case.yaml` and no tutorial contract). Their data and results are real, but they do not represent future junior study state. Preserve provenance and never import tutorial choices as confirmed human decisions.

The tutorial preparation scripts (`prepare_bank.py`, `prepare_auto_mpg.py`) train models when explicitly executed; the `prepare.py` of the scikit-learn cases only copies data. Simply opening existing outputs does not train a model. The experimental runtime's `prepare_discovery.py` enriches tutorial contracts and is not the new workflow entry point.
